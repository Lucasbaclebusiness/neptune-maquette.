# Neptune - maquette

Maquette cliquable du site Neptune (parcours prospect, page clipper, espace client, espace clipper, fiche de closing).

- `public/` : les pages (format Design Component) et le moteur `support.js`
- `server.js` : petit serveur Node sans dépendance
- Variable optionnelle `SITE_PASSWORD` : protège le site par mot de passe
